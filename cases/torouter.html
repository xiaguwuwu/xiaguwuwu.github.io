ToRouter 激活与留存方案

产品
ToRouter
角色
AI 产品经理
时间
2026.05 – 2026.06

项目

ToRouter 是面向 AI 编程用户的大模型 API 网关，一个 Key 就能在 Claude Code、Codex 等工具里调用多家模型。新用户卡在四个地方：

  • 注册后不知道先接哪个工具、用哪个模型。
  • 充值动机不具体，感知不到充值能换来什么。
  • 签到、邀请、返券分散在不同入口。
  • 看不到费率、失败原因和用量明细。

过程

层目标产品动作
激活3 分钟内完成首次有效调用按工具生成配置的接入向导、一键测试连接、按场景推荐模型
付费充值和真实权益绑定真实充值进入 VIP；低价分组只对充值用户开放；三档套餐
留存持续回来、放心用低余额提醒、单 Key 日限额和月预算、按工具展示用量
增长老用户带新用户邀请奖励以被邀请人完成首次调用为触发点

官网小需求排不上开发排期，我用 Codex 自己写代码、提合并请求。

结果

  • 四层方案做成 7 个页面的可交互原型供评审。
  • 独立上线 4 个官网需求：接入 Google Tag Manager 补齐埋点、博客图片上传并自动转 WebP、国家与地区页、精简版法律文档。
