ToRouter Activation and Retention Plan

Product
ToRouter
Role
AI Product Manager
Dates
2026.05 – 2026.06

Project

ToRouter is an LLM API gateway for AI coding users: one key calls models from several providers inside tools like Claude Code and Codex. New users got stuck in four places:

  • After sign-up they didn’t know which tool to connect first or which model to use.
  • No concrete reason to top up: they couldn’t see what a top-up would get them.
  • Check-ins, invites and coupons sat behind different entry points.
  • Rates, failure reasons and usage details were hard to see.

Process

LayerGoalProduct moves
ActivationFirst successful call within 3 minutesSetup wizard that generates config per tool, one-click connection test, model suggestions by scenario
PaymentTie top-ups to real benefitsReal top-ups unlock VIP; low-price groups only for paying users; three plans
RetentionKeep coming back, use without worryLow-balance alerts, per-key daily limits and monthly budgets, usage shown by tool
GrowthExisting users bring new onesInvite rewards trigger when the invitee makes a first call

Small website requirements couldn’t get a dev slot, so I wrote the code with Codex and opened the merge requests myself.

Results

  • Built the four-layer plan as an interactive prototype of 7 pages for review.
  • Shipped 4 website requirements on my own: Google Tag Manager for event tracking, blog image upload with automatic WebP conversion, country and region pages, short-form legal pages.
