Rebuilding Product Work with Claude Code

Product
VerseIn, ToRouter
Role
Initiator
Dates
2026.05 – 2026.11

Project

I covered both model lines, video and image (30+ models), listing and ranking for nearly 600 templates, plus pricing and new-user conversion. Done by hand, three kinds of work filled the week:

  • Scattered monitoring: trends were spread across Reddit, Instagram, Xiaohongshu and competitor sites, and missing things was normal.
  • Error-prone config: one template meant 20+ fields, and a missing translation meant users saw English everywhere.
  • Slow data pulls: every homepage re-rank meant exporting tables from the backend and joining them by hand.

Process

StepAutomation
Trend monitoringScheduled trend reports for three platforms; a real browser scrapes competitors’ most-liked lists for a weekly comparison
Viral breakdownsGive it a video: it samples frames with captions, breaks the video down by cover, hook, emotion and input bar, and writes a prompt
Template configCopy, tags, icon, cover compression and 7 translations in one go, read back to verify, saved as a draft by default
Tag opsA weekly run of trend extraction, new tags, tagging new templates and auditing old ones; renames, merges and deletions only produce proposals and never run on their own
Data analysisPulls full data straight from APIs; re-ranking and analysis are scripts, checked automatically after writing to production

Principles: read the code before describing app behavior, and read official docs before describing upstream capabilities; every analysis keeps its script and snapshot; renames, deletions and anything that spends money only produce a proposal for a person to approve.

Results

  • 11 weekly tag reviews so far; as of Nov 2, 158 templates site-wide still had no tags, and tagging is catching up on the backlog.
  • Shipped 4 website requirements on my own with AI coding (see ToRouter).
